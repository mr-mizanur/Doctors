# Doctors

## Project Overview
Doctor Tracker is a secure administrative web application designed to manage doctors and their corresponding patients efficiently. The platform provides full CRUD functionality, fast searchable directories, specialty and condition filters, date-based filtering, server-side pagination, and an interactive analytics dashboard for monitoring total doctors and patient activity.

---

## Frontend Tech Stack & Features

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS (Clean Light/Pro UI Theme)
- **Icons:** React Icons (`react-icons/fa`, `react-icons/fi`)
- **Authentication:** Better Auth (Secure Email & Password authentication with route protection)
- **State & Data Fetching:** React Hooks (`useState`, `useEffect`) fetching data via REST APIs

---

## Core Modules
- **Dashboard:** Real-time statistics, doctor & patient counts, and analytics summary.
- **Doctor Management:** Create, view, search, filter, paginate, and delete doctor profiles with assigned patients.
- **Patient Management:** Dedicated patient page with search, condition filtering, edit, and delete features.
